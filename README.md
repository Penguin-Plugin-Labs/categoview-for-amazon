# CategoView for Amazon

**Display Amazon product carousels on your WordPress site using the Amazon Creators API.**

CategoView for Amazon is a WordPress plugin that lets you select Amazon product categories, build a product catalog, and display products in a carousel on your website.

Set up your catalog once and let the plugin keep product information updated automatically.

## Features

- **Category-based product catalogs** — Select Amazon product categories using Browse Node IDs.
- **Automatic catalog updates** — Retrieve and update product information through the Amazon Creators API.
- **Product carousels** — Display products in a carousel on your WordPress site.
- **Block and widget support** — Add product carousels using the WordPress block editor or widgets.
- **Free and Pro versions** — Start with the free version and explore additional features in Pro.

## Requirements

- A WordPress website.
- Access to the Amazon Creators API and the credentials required to use it.
- Compliance with the applicable Amazon Associates Program policies and API terms.

## Installation

1. In your WordPress dashboard, go to **Plugins → Add New Plugin**.
2. Search for **CategoView for Amazon**.
3. Install and activate the plugin.
4. Configure your Amazon Creators API credentials.
5. Select a product category, build your catalog, and add a carousel to your site.

For detailed setup instructions, see the tutorial below.
